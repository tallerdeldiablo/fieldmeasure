# FieldMeasure

Field measurement app concept for shade and window-treatment installers.

## Goal

Create a simple mobile-first workflow for field measurements:

1. Create a project
2. Add rooms
3. Add windows/openings
4. Record width and height
5. Store notes and photos
6. Prepare for Bluetooth laser measurements
7. Export project data

## Current Prototype

The initial prototype is intentionally basic and focuses on layout and navigation.

### Screens

- Projects
- Project / Rooms
- Room / Windows
- Gallery
- Settings

### Planned Features

- Inches and fractional measurements
- Bluetooth laser integration
- Auto-advance measurement workflow
- Notes and drawings
- Photos for each opening
- Offline storage
- PDF / CSV export
- Quick Measure mode
